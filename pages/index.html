How to install

  1. Tap Download for Android on the phone.
  2. Open robi.apk from the notifications or the Downloads folder.
  3. If Android asks, allow installing apps from this source.
  4. Turn on NFC in the phone settings.

New versions install over the old one. All versions are listed on the releases page.
